# Release Notes - AppForm v1.0.0 Stable

Welcome to the production stable release of **AppForm v1.0.0**.

## Highlights
- **Active Directory / LDAP Authentication Support**: Secure binding and directory sync.
- **Enterprise Hierarchy Management**: Set managers and explore the organization reporting tree.
- **Improved UX / Wide Form Builder**: Expanded layout for designing large forms.
- **System Health Dashboard**: System stats at a glance.
