# Installation Instructions

## Requirements
- PHP 8.1 or higher
- SQLite / MySQL Database
- Web server (Apache, Nginx, or IIS)

## Quick Start
1. Extract the release zip.
2. Configure settings inside `config/config.php`.
3. Import database structure from `db/schema.sql`.
4. Run migrations using the command line runner or web installer.
5. Log in with the default Administrator credentials.
